# Disciple.Tools - Africa DMM (Deprecated)

> **This plugin is deprecated and no longer maintained.** If it is installed on your site, deactivate and delete it.

The plugin read group reports sent over WhatsApp through the Disciple.Tools Twilio channel. It used them to create and update group records, and it added Group Leader and Group Coach fields to the groups Four Fields tile. It was never published as a release. The repository is archived and read-only.
